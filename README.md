## Current Projects

### Robie

A local-first voice assistant running on Raspberry Pi.

Robie explores speech recognition, intent routing, local LLM orchestration, fuzzy matching, audio playback management, and embedded AI systems.

**Stack**

`Python` · `Vosk` · `Qwen` · `Raspberry Pi` · `TTS` · `mpv`

Repository:

👉 <https://github.com/fabiencappelli/Robie>

---

### Releaser

A pipeline that transforms Jira exports into narrated release videos.

The project parses Jira tickets, groups them into coherent themes, generates presentation scripts using LLMs, synthesizes voice narration, and automatically renders a final MP4 release video.

**Stack**

`Python` · `OpenAI API` · `BeautifulSoup` · `FFmpeg` · `Pydub`

Repository:

👉 <https://github.com/fabiencappelli/releaser>

## Philosophy

I am less interested in building impressive demos than in building systems that survive contact with reality.

That usually means:

- imperfect data,
- strange edge cases,
- human constraints,
- legacy systems,
- documentation,
- and a lot of conversations.

That's where the interesting problems tend to live.
